# Графовые алгоритмы на Python

Программа предоставляет инструменты для генерации, анализа и визуализации неориентированных графов. Она позволяет:

- генерировать матрицу смежности для различных типов графов (простые, полные, с петлями, мультиграфы);
- строить матрицу инцидентности и список рёбер;
- находить кратчайшие расстояния между вершинами методом умножения матриц;
- вычислять радиус, диаметр, центральные и периферийные вершины графа;
- находить хроматическое число графа с помощью жадной раскраски вершин;
- находить все максимальные независимые множества (методом Магу — Вейсмана) и наибольшее из них;
- визуализировать граф с отображением красок вершин, кратных рёбер и петель.

---

## Требования

- Python 3.6 или выше
- Библиотеки:
  - `networkx`
  - `matplotlib`

Установка зависимостей:

```bash
pip install networkx matplotlib
```

---

## Запуск

Сохраните код в файл (например, `graph_analysis.py`) и выполните:

```bash
python graph_analysis.py
```

Программа последовательно:

1. запросит параметры для генерации матрицы смежности;
2. выведет матрицу смежности, матрицу инцидентности и список рёбер;
3. вычислит и выведет матрицу кратчайших путей, радиус, диаметр, центральные и периферийные вершины;
4. найдёт все максимальные независимые множества и наибольшее из них;
5. отобразит визуализацию графа с раскраской вершин (жадный алгоритм) и покажет хроматическое число.

## Описание работы

### 1. Генерация матрицы смежности

Функция `generate_adjacency_matrix()` запрашивает у пользователя:

- `mode` — тип графа:
  - `1` — простой граф (без петель, рёбра 0 или 1);
  - `2` — полный граф (каждая пара вершин соединена ребром);
  - `3` — граф с петлями (на диагонали возможны единицы);
  - `4` — мультиграф (кратность рёбер от 0 до 3, включая мультипетли).
- `n` — количество вершин (размер матрицы).

Для типов 1, 3, 4 матрица заполняется случайными числами в верхнем треугольнике (включая диагональ для типа 3) и симметрично копируется в нижний. Для полного графа все внедиагональные элементы равны 1.

Если введён номер, отличный от 1–4, используется предопределённая тестовая матрица (например, для отладки).

### 2. Вывод матрицы смежности

Функция `display_matrix()` выводит матрицу в виде отформатированной таблицы с индексами строк и столбцов.

### 3. Матрица инцидентности и список рёбер

Функция `build_incidence_matrix()` по матрице смежности строит:

- `inc` — матрицу инцидентности размера `n × m`, где `m` — общее количество рёбер с учётом кратности. Для обычного ребра в столбце ставятся `1` в строках инцидентных вершин, для петли — `2`.
- `edges` — список кортежей `(u, v)`, описывающих все рёбра в порядке следования столбцов матрицы инцидентности.

Вывод матрицы инцидентности выполняется функцией `display_incidence_matrix()`, а список рёбер (в виде двух строк: "От" и "До") — `display_edges_list()`.

### 4. Жадная раскраска вершин и хроматическое число

Внутри функции `visualize_graph()` перед визуализацией выполняется **жадная раскраска** вершин:

- Вершины перебираются в порядке возрастания индексов.
- Для текущей вершины собираются цвета уже окрашенных соседей.
- Назначается первый доступный цвет из предопределённой палитры (`ColorDict`).
- После окраски всех вершин вычисляется **хроматическое число** — количество различных использованных цветов.
- Цвета сохраняются в массив `ColorMatrix`, который затем используется для отображения вершин.

**Примечание:** жадная раскраска не гарантирует минимальное хроматическое число, но даёт его верхнюю оценку. Для небольших графов результат часто совпадает с точным.

### 5. Поиск кратчайших путей (лабораторная работа 2)

Функция `compute_shortest_paths_matrix()` реализует алгоритм на основе **возведения матрицы смежности в степень**:

- Матрица расстояний `output_matrix` инициализируется `-1` (неизвестно), на диагонали — `0`.
- Прямые рёбра дают расстояние `1`.
- На каждом шаге `k` (начиная с 2) матрица `current_power` умножается на исходную матрицу смежности.
- Если элемент `(i,j)` в очередной степени становится положительным, а в матрице расстояний всё ещё `-1`, записывается `k`.
- Алгоритм останавливается, когда на очередном шаге не найдено новых путей или `k` достигло `n` (максимальная длина простого пути). Все оставшиеся `-1` заменяются на `0` (отсутствие пути).

На выходе получается матрица кратчайших расстояний между всеми парами вершин (в одной компоненте связности).

### 6. Радиус, диаметр, центральные и периферийные вершины

Функция `calculate_radius_and_diameter()` принимает матрицу кратчайших путей и:

- Для каждой вершины вычисляет эксцентриситет — максимум расстояний от неё до остальных вершин (включая компоненты связности, где расстояние 0 интерпретируется как отсутствие пути).
- Находит **радиус** как минимальный эксцентриситет среди всех вершин.
- Находит **диаметр** как максимальный эксцентриситет.
- Определяет **центральные вершины** (эксцентриситет равен радиусу), **периферийные вершины** (эксцентриситет равен диаметру) и **изолированные вершины** (эксцентриситет равен 0).
- Выводит расширенную матрицу расстояний с дополнительным столбцом «max» (эксцентриситет) и перечисляет найденные вершины.

### 7. Максимальные независимые множества (лабораторная работа 3)

Функция `magu_weissman_maximal_independent_sets()` реализует **метод Магу — Вейсмана** для нахождения всех максимальных независимых множеств графа.

Алгоритм (построение ДНФ из КНФ):

1. Для каждого ребра `(i, j)` строится дизъюнкт (скобка) `{i, j}` — утверждение, что хотя бы одна из вершин должна быть удалена (или, эквивалентно, независимое множество не может содержать обе вершины ребра). Для графа без рёбер сразу возвращается множество всех вершин.
2. Последовательно перемножаются скобки с использованием законов дистрибутивности, идемпотентности и поглощения (удаление термов, содержащих другой терм как подмножество).
3. В результате получаются **минимальные вершинные покрытия** (в терминах удаляемых вершин). Чтобы получить **максимальные независимые множества**, из полного множества вершин вычитается каждое вершинное покрытие.
4. Возвращается список независимых множеств (как `set` вершин). Затем выбирается наибольшее из них.

**Важно:** алгоритм может быть экспоненциальным по времени, но для небольших графов (обычно до 20–25 вершин) работает приемлемо.

### 8. Визуализация

Функция `visualize_graph()`:

- Создаёт мультиграф `networkx.MultiGraph` и добавляет все вершины и рёбра с учётом кратности.
- Использует жадную раскраску (см. п. 4) и передаёт цвета в `node_color`.
- Располагает вершины по алгоритму `spring_layout`.
- Отрисовывает кратные рёбра с разными радиусами изгиба (значения `rad`), чтобы они не сливались. Петли рисуются стандартным способом.
- Отключает оси и показывает окно с графом.

## Теоретическое обоснование

### Кратчайшие пути через степени матрицы смежности

Для графа (в том числе мультиграфа) элемент `(A^k)[i][j]` равен количеству различных путей длины `k` из `i` в `j` (с возможными повторениями вершин). Если `(A^k)[i][j] > 0`, то существует хотя бы один путь длины `k`. Минимальное такое `k` и есть кратчайшее расстояние.

Алгоритм последовательно вычисляет `A^1, A^2, ...` и фиксирует первое появление ненулевого значения. Поскольку в графе без циклов максимальная длина простого пути не превышает `n-1`, а при наличии циклов дальнейшие степени не уменьшают расстояние, алгоритм корректен и останавливается за `O(n^4)` (умножение матриц `n×n` выполняется `O(n)` раз).

### Радиус и диаметр

Эксцентриситет вершины `v` — `max_{u ∈ V} dist(v, u)`. Радиус — `min_v ecc(v)`, диаметр — `max_v ecc(v)`. Центральные вершины часто используются при размещении серверов или складов, периферийные — для анализа удалённости.

### Жадная раскраска

Окрашивает вершины последовательно, выбирая минимальный цвет, не используемый соседями. Количество использованных цветов — верхняя оценка хроматического числа. Для некоторых классов графов (например, двудольных) эта оценка точна.

### Метод Магу — Вейсмана

Пусть граф `G = (V, E)`. Множество вершин `S ⊆ V` является **независимым** ⇔ `S` не содержит концов ни одного ребра. Иначе говоря, `V \ S` должно быть вершинным покрытием (пересекать все рёбра). Представим условие покрытия в виде КНФ: для каждого ребра `(i, j)` дизъюнкт `(i ∨ j)` означает, что покрытие должно включать хотя бы `i` или `j`. Умножая эти дизъюнкты (раскрывая скобки), получаем ДНФ — совокупность минимальных вершинных покрытий. Их дополнения до `V` — максимальные независимые множества. Поглощение устраняет избыточные термы.

## Примечания

- Для мультиграфов алгоритм нахождения максимальных независимых множеств работает корректно (кратность рёбер не влияет на независимость).
- Петли делают невозможным включение вершины в независимое множество, так как вершина инцидентна сама себе (но алгоритм Магу — Вейсмана строит дизъюнкты только для пар `i≠j`? В текущей реализации петли **не** добавляются в список дизъюнктов, поэтому вершина с петлёй может быть включена в независимое множество — это некорректно. При необходимости можно модифицировать код, добавив для каждой петли `(i,i)` дизъюнкт `{i}`.)
- Визуализация может быть неидеальной для очень больших графов (более 30 вершин) из-за наложения надписей.
