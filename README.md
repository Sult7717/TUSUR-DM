# Графовые алгоритмы на Python

Программа предоставляет инструменты для генерации, анализа и визуализации неориентированных графов. Она позволяет:

- генерировать матрицу смежности для различных типов графов (простые, полные, с петлями, мультиграфы);
- строить матрицу инцидентности и список рёбер;
- находить кратчайшие расстояния между вершинами методом умножения матриц;
- вычислять радиус и диаметр графа;
- визуализировать граф с помощью библиотек `networkx` и `matplotlib`.

---

## Требования

- Python 3.6 или выше
- Библиотеки:
  - `networkx`
  - `matplotlib`

Установка зависимостей:

```bash
pip install networkx matplotlib
```

```bash

```

Программа предложит ввести размер матрицы и выбрать тип генерируемого графа.

## Описание работы

### 1. Генерация матрицы смежности

Функция `gen_matrix()` запрашивает у пользователя:

- `n` — количество вершин;
- `mode` — тип графа:
  - `1` — простой граф (без петель, рёбра 0 или 1);
  - `2` — полный граф (каждая пара вершин соединена ребром);
  - `3` — граф с петлями (на диагонали возможны единицы);
  - `4` — мультиграф (кратность рёбер от 0 до 3, включая мультипетли).

Матрица заполняется случайным образом (для типов 1, 3, 4) в верхнем треугольнике и симметрично копируется в нижний, так как граф неориентированный.

### 2. Вывод матрицы смежности

Функция `print_matrix()` выводит матрицу в виде отформатированной таблицы с индексами строк и столбцов.

### 3. Матрица инцидентности и список рёбер

Функция `incidence_matrix()` по матрице смежности строит:

- `inc` — матрицу инцидентности размера `n × m`, где `n` — число вершин, `m` — общее количество рёбер с учётом кратности. Для обычного ребра в столбце стоят 1 в строках инцидентных вершин, для петли — 2.
- `edges` — список кортежей `(u, v)`, описывающих все рёбра.

Вывод матрицы инцидентности выполняется функцией `print_incidence_matrix()`, а список рёбер — `print_edges()`.

### 4. Поиск кратчайших путей

Алгоритм в функции `find_path()` основан на **возведении матрицы смежности в степень**.

- Начальная матрица расстояний `output_matrix` инициализируется значениями `-1` (неизвестно), на главной диагонали — `0`.
- Если в исходной матрице смежности есть ребро, то расстояние равно `1`.
- На каждом шаге `k` текущая степень матрицы смежности умножается на исходную матрицу, получая матрицу `A^k`. Если элемент `(i,j)` в `A^k` становится положительным, а в матрице расстояний ещё `-1`, то записываем `k`.
- Процесс продолжается, пока на очередном шаге не будет найдено ни одного нового пути, либо пока `k` не достигнет `n` (максимально возможная длина простого пути).

На выходе получаем матрицу кратчайших расстояний, где `0` означает отсутствие пути (если вершины принадлежат разным компонентам связности).

### 5. Радиус и диаметр

Функция `find_radius_diameter()`:

- Находит эксцентриситет каждой вершины — максимум расстояний от неё до всех остальных вершин в той же компоненте связности.
- Вычисляет **радиус** графа как минимальный эксцентриситет среди вершин, имеющих хотя бы одно соединение.
- Вычисляет **диаметр** как максимальный эксцентриситет.

Результаты выводятся в консоль в виде расширенной матрицы расстояний с колонкой `max` (эксцентриситет).

### 6. Визуализация

Функция `draw_graph()` строит изображение графа с помощью `networkx` и `matplotlib`. Учитываются кратные рёбра (отображаются с изгибом) и петли. Вершины располагаются по алгоритму `spring_layout`, что даёт наглядное представление структуры графа.

## Теоретическое обоснование

### Основные определения

- **Граф** — множество вершин `V` и множество рёбер `E`, соединяющих пары вершин.
- **Матрица смежности** `A` размера `n×n`, где `A[i][j]` равно числу рёбер между вершинами `i` и `j`.
- **Матрица инцидентности** `B` размера `n×m`, где `B[i][j]` показывает, инцидентна ли вершина `i` ребру `j` (1 для обычного ребра, 2 для петли).
- **Путь** — последовательность вершин, соединённых рёбрами. **Кратчайший путь** — путь минимальной длины.
- **Эксцентриситет** вершины — наибольшее из кратчайших расстояний от данной вершины до всех остальных.
- **Радиус** графа — минимальный эксцентриситет.
- **Диаметр** — максимальный эксцентриситет.

### Алгоритм нахождения расстояний через степени матрицы смежности

Известно, что `(i,j)`-й элемент матрицы `A^k` равен **количеству путей длины `k`** из вершины `i` в вершину `j` (включая повторные проходы по вершинам и рёбрам).

Поэтому если `A^k[i][j] > 0`, то существует хотя бы один путь длины `k` между `i` и `j`. Кратчайшее расстояние — минимальное `k`, при котором появляется ненулевой элемент. Алгоритм последовательно проверяет степени `k = 1, 2, …` и заполняет матрицу расстояний при первом появлении пути.

Такой подход работает для любых графов, в том числе мультиграфов и графов с петлями, поскольку нас интересует **существование** пути, а не их количество. В случае мультиграфа кратность рёбер не влияет на расстояние, а петля даёт путь длины 1 из вершины в саму себя (что уже учтено нулём на диагонали).

### Корректность остановки

Максимальная длина простого пути (без повторения вершин) в графе с `n` вершинами не превышает `n-1`. Если за `n` шагов не появилось новых ненулевых элементов, то дальнейшее умножение также не даст новых связей, так как граф не содержит новых компонент. Поэтому алгоритм завершается не позднее чем через `n` итераций.

### Вычисление радиуса и диаметра

После получения матрицы кратчайших расстояний эксцентриситет вершины вычисляется как максимум по строке (игнорируя нули для недостижимых вершин). Радиус и диаметр определяются по множеству эксцентриситетов вершин, принадлежащих компонентам связности с более чем одной вершиной (либо с учётом изолированных вершин, где эксцентриситет 0, что не влияет на радиус и диаметр).

---

## Ограничения и возможные улучшения

- Генерация мультиграфа фиксирует максимальную кратность рёбер = 3. Это легко изменить в коде.
- Визуализация может быть перегружена при большом количестве кратных рёбер.
- Алгоритм поиска путей не оптимизирован для очень больших графов; для них эффективнее использовать алгоритм Флойда–Уоршелла или BFS.
- Программа работает только с неориентированными графами.
